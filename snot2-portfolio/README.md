# Snot2 Portfolio v2

A framework-free personal portfolio designed for Snot2.

## Preview locally
Open `index.html` in your browser.

## Deploy to Cloudflare Pages
This site is completely static, so no build command is needed.

- Framework preset: None
- Build command: leave empty
- Build output directory: `/`

## Before publishing
Replace the placeholder GitHub button in `index.html` with your real GitHub profile URL.

## Files
- `index.html` — site structure/content
- `styles.css` — layout, visual design, responsive styles and animation
- `script.js` — reveal effects, live New York clock, scroll progress, mobile nav, cursor, Discord copy button
